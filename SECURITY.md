# Security

Report a vulnerability privately through GitHub's private vulnerability reporting: on the
[Security tab of RunesmithHub/HammerUI](https://github.com/RunesmithHub/HammerUI/security), choose **Report a vulnerability**, or open
[a new advisory](https://github.com/RunesmithHub/HammerUI/security/advisories/new) directly. Please do not open a public issue for it.

Describe what is affected, how to reproduce it and what an attacker could do with it. Fixes go into `main` and the next release.
